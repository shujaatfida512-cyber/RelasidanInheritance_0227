# Relationships & Inheritance — C++

A set of C++ examples demonstrating major object-oriented relationships and inheritance concepts.

## Topics Covered
- Inheritance
- Association
- Aggregation
- Composition
- Classes and objects
- Constructors and destructors
- Vectors and object relationships
- Basic member-management logic

## Examples
The exercises model relationships such as people and students, doctors and patients, parents and children, and a human containing a heart object.

## Purpose
Created to understand how objects interact and how different OOP relationships are represented in C++.
